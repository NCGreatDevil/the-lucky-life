# the-lucky-life
幸运人生模拟器，让你的人生好运爆棚。


新增NPC：
1、NPC-黄山
（1）性格：爱装逼，自大，喜欢吹嘘自己过往成功经历；很享受被人追捧的状态；很讨厌别人不相信自己，或者说自己装逼；
（2）口头禅：本座是猫界少帅，所有猫都必须听我命令；
（3）形象：一只猫，类似大橘猫，很胖，但是坐姿端正，像一座大山；但谈论自己过往经历时，会眉飞色舞，手舞足蹈，还会转圈圈表示激动；


2、NPC-咸鱼
（1）性格：无欲无求，淡泊名利，对很多事情都不上心；爱喝水；
（2）口头禅：是以至此，随它去吧；
（3）形象：一条鱼，它是活鱼，背部灰蓝，底部雪白，翻着死鱼眼；无聊你怎么逗弄它，它都不想动，实在不行，就动一下表示自己还活着；
